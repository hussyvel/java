1. Visão Geral do Sistema

O Sistema Patrimonial é uma aplicação web para gerenciamento de patrimônio (bens materiais) de uma organização. Permite cadastrar bens, controlar empréstimos e devoluções, transferências entre setores, emitir relatórios e gerenciar usuários com diferentes perfis de acesso.

Módulo Principal
Gestão de Bens (Patrimônio)
Módulo de Controle
Saídas, Devoluções e Transferências
Módulo de Relatórios
PDF e Excel com filtros
Módulo de Usuários
Admin e Operador (RBAC)

Funcionalidades Principais

FuncionalidadeDescriçãoPerfil
Cadastro de BensCriar, editar, excluir e buscar bens patrimoniaisAdmin / Operador
Registro de SaídaEmprestar bem a um responsável com destino registradoAdmin / Operador
Registro de DevoluçãoConfirmar retorno do bem, restaura status para ATIVOAdmin / Operador
Transferência de SetorMover bem permanentemente entre setoresAdmin / Operador
DashboardTotais por categoria, status e valor patrimonialAdmin / Operador
Relatório PDFRelatório de bens com filtros, download diretoAdmin
Relatório ExcelPlanilha de bens com filtros, download diretoAdmin
Gestão de UsuáriosCriar, editar, ativar/inativar, excluir usuáriosAdmin
Recuperação de SenhaEnvio de link de reset por e-mailPúblico
Visão por SetorAgrupar bens por setor com resumoAdmin / Operador
Credencial padrão: Na primeira execução, o sistema cria automaticamente um usuário login: admin / senha: admin123 se não houver usuários cadastrados.

6. Segurança

Autenticação baseada em sessão HTTP gerenciada pelo Spring Security. CSRF desabilitado. Senhas armazenadas com BCrypt.

Regras de Acesso (SecurityConfig)

/GETPúblico
/api/bens/**GETAutenticado
/api/movimentacoes/**TodosAutenticado
/api/bens/**POST, PUT, DELETEAutenticado
/api/usuarios/**TodosROLE_ADMIN
/api/relatorios/**TodosROLE_ADMIN

Perfis de Usuário

PerfilRole Spring SecurityPermissões
ADMIN ROLE_ADMIN Acesso total: bens, movimentações, usuários, relatórios
OPERADOR ROLE_OPERADOR Consultar bens, registrar saídas e devoluções, transferências
Usuário inativo: Se ativo=false, o Spring Security lança DisabledException e o login retorna 401. O campo é gerenciado por ADMIN via PUT /api/usuarios/{id}.

Fluxo de Recuperação de Senha

EndpointDescrição
POST /api/auth/esqueci-senhaRecebe o e-mail, gera token e envia link de reset

9. Docker e Docker Compose

O projeto inclui Dockerfile com build multi-estágio e docker-compose.yml que orquestra a aplicação + PostgreSQL. Resolve o problema de versão de Java e conflito de portas.

Dockerfile (multi-estágio)

# Estágio 1: build com Maven + Java 17 FROM maven:3.9.6-eclipse-temurin-17 AS build WORKDIR /app COPY pom.xml . RUN mvn dependency:go-offline -q COPY src ./src RUN mvn package -DskipTests -q # Estágio 2: imagem final enxuta FROM eclipse-temurin:17-jre-jammy WORKDIR /app COPY --from=build /app/target/*.jar app.jar EXPOSE 8080 ENTRYPOINT ["java", "-jar", "app.jar"]

12. Resolução de Problemas

ProblemaCausaSolução
UnsupportedClassVersionError (class file version 61.0) Maven rodando com Java 11 em vez de Java 17 Prefixar o comando com JAVA_HOME=/usr/lib/jvm/java-1.17.0-openjdk-amd64 ou configurar no ~/.bashrc
Port 8080 already in use Outro processo usando a porta Identificar com sudo lsof -i:8080 e matar, ou usar porta diferente com --server.port=8082
Connection refused (PostgreSQL) PostgreSQL não está rodando Iniciar com sudo systemctl start postgresql ou usar docker compose up db
FATAL: database "patrimonio" does not exist Banco não criado Criar com createdb -U postgres patrimonio ou deixar o Docker criar automaticamente
401 em todas as requisições Sessão expirada ou não autenticado Fazer login novamente em POST /api/auth/login
403 Forbidden Usuário OPERADOR acessando rota de ADMIN Usar conta com perfil ADMIN para /api/usuarios/** e /api/relatorios/**
Docker: image not rebuilding Cache do Docker Forçar rebuild com docker compose build --no-cache
E-mail de reset não chega App Password do Gmail inválida ou SMTP bloqueado Gerar nova App Password em Conta Google → Segurança → Senhas de app
Java 17 instalado mas não reconhecido pelo Maven?
Verifique quais versões estão disponíveis: update-java-alternatives -l
Use sempre o prefixo JAVA_HOME=... ou troque o Java padrão do sistema: sudo update-alternatives --config java
